# ModuKitchen

## Project Overview

ModuKitchen is a modular kitchen design and services website
built with Payload CMS and Next.js.

The platform showcases kitchen designs, completed projects,
materials, finishes, and available services while allowing
potential customers to submit quotation inquiries.

## Project Objectives

- Learn Payload CMS through practical development.
- Build a modern, responsive, CMS-driven website.
- Implement reusable and maintainable content structures.
- Establish automated testing and development standards.
- Explore AI-assisted development using Claude Code.
- Prepare the application for deployment to Vercel.

## Core Features

- Dynamic landing pages
- Kitchen design catalogue
- Project portfolio and filtering
- Materials and finishes catalogue
- Services pages
- Customer testimonials
- Quotation inquiry forms
- Inquiry management
- Email notifications
- SEO and metadata management

## Project Scope

ModuKitchen is a lead-generation and portfolio website,
not an e-commerce platform.

Shopping carts, online payments, and order fulfilment
are outside the initial project scope.

## Development Approach

- Code-first CMS configuration
- Type-safe development
- Reusable components
- Automated integration and end-to-end testing
- Incremental development
- Git checkpoints every one or two lessons
